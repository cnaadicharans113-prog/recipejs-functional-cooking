🍳 RecipeJS – Functional Cooking Companion

RecipeJS is a simple web application built using HTML, CSS, and JavaScript that displays food recipes dynamically using functional programming concepts.

This project is part of the Kalvium CNAC curriculum.

🚀 Features

Dynamic recipe cards rendered from JavaScript

Clean and responsive UI using Flexbox

Hover effects and difficulty badges

Semantic HTML structure

Beginner-friendly, clean code

🛠️ Tech Stack

HTML5

CSS3

JavaScript (ES6)

📂 Project Structure
recipejs-functional-cooking/
├── index.html
├── style.css
├── app.js
└── README.md

▶️ How to Run

Clone the repository

Open index.html in any browser

DOM manipulation

Arrow functions

Template literals

Array map() method

Separation of concerns
